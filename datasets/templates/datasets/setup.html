Scope

The window and per-series minimum below are discovery filters: a site only qualifies if its series overlap this window and carry at least this many observations.

Parameter groups

A site qualifies only if it has data in every group. Inside a group, values are normalized to the group's most common unit; codes that cannot be converted are excluded and reported.

Search by code (00060) or by name (nitrate). Units are shown per code so you can see before you commit whether a group will need conversion.

Data services

A site must have a matching series in at least one checked service. Only daily values (dv) are downloaded and analyzed; the others act purely as site filters. USGS retired the qw download endpoint in 2024.

States

Discovery runs one NWIS inventory query per state.
